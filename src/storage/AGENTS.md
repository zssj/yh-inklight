成员清单
types.ts: sidecar JSON、注释、便签、代码选区标记、设置（含 contentRelations 字面关联开关）、索引的类型真相源。
annotationStore.ts: .obsidian-annotations 持久化入口，负责文件 JSON、index、标签字典、导出与迁移；标签管理提供 getTagUsage / renameTag / deleteTag：重命名按 tagKey 合并同名标签、删除只摘标签不删批注，均逐文件 saveDocument 并把失败文件列在结果里，最后用 persistTagNames 按索引实际 key 重建 tagNames（saveDocument 的 mergeTagNames 只增不删，不重建会留下旧 key）；导出笔记可选写入 OB 可索引的 frontmatter tags 与正文 #标签（受控标记保护用户 frontmatter）；正文按批注块增量合并——每块用 HTML 注释边界包住，重复导出只替换同 id 块，块外用户手写内容原样保留，老格式回退 callout+block-id 推断；回链统一走 `obsidian://inklight?file=&mode=&offset=|page=|cfi=&text=` 协议链接（生成见 sourceLink.buildSourceLinkUrl，解析见 main.openSourceLink；**不能**用 `#^<blockId>` 自引用锚点：它指向导出笔记自身，只靠 EpubGotoHandler 劫持才生效，MOC 页不在其路径白名单里就会点击无反应；也**不能**用 `[[源文件]]` 或 `[[源文件#page=N]]`：前者只能落到文件头，后者赌 Obsidian 私有锚点语法）；按标签导出 MOC 页 exportTagMoc——目标固定 vault 根 MOC/<标签>.md（文件夹无则新建），文件名由 tagKey 派生、标题固定为标签显示名（签名稳定，靠 `# <标签>` 行识别墨光生成页，非墨光生成的同名页拒绝覆盖返回 skipped-foreign）。改名/移动迁移提供 migrateFilePath（单文件）与 migrateFilePaths（批量：逐条搬迁 sidecar 并在全部结束后只写一次索引；文件名变了但内容没变，hash 沿用旧值、不重算）。文件夹改名时 main.ts 按旧/新前缀反查 listIndexedPaths 补齐子树文件，不依赖 Obsidian 是否给每个子文件发 rename 事件。外部移动/同步盘替换可能完全不发 rename，findRelocatablePaths 按「唯一同名文件」找回失联条目（零候选/多候选不碰），供 plugin.recoverAnnotationIndex 启动自愈与设置页手动修复。**索引是查找表、sidecar 才是权威**：rename 迁移写索引失败（进程被杀写半截、同步盘旧快照覆盖、批量中途抛错）后，真机表现是「单本打开有批注、全库一片空白」——因为 getDocument 按新路径算 sidecar 能读到，而 getIndexedDocuments 按索引旧路径过滤文件不存在。因此 migrateOne 在旧 sidecar 缺失时会 adoptMigratedSidecar 认领新路径 sidecar 补索引（反查指针从旧条目带过来），migrateFilePaths 逐条 try/catch 不再一条失败中断整批（否则前面 sidecar 已搬、索引一条没落地）；索引读坏不再静默退回空索引，而是备份 index.corrupt-*.json 并置 indexNeedsRebuild，rebuildIndexFromSidecars 只读「未被有效条目引用」的 sidecar 整体重建（正常库零 IO）。
sourceLink.ts: 回链契约纯函数（buildSourceLinkUrl / parseSourceLinkParams / refineOffset / encodeLinkValue），导出层与协议解析端共用同一套编码规则，无 IO。协议值须额外转义 `( ) ! ' *`——encodeURIComponent 不转义它们，而 CFI 与含括号书名会让 Markdown 链接在第一个 `)` 处截断；refineOffset 用链接携带的原文片段给 drift 过的 startOffset 做就近校正，片段不足 4 字或找不到时保守返回原偏移。
结构化导出字段: 每条批注在 callout 之外、受控块之内追加 `noteType:: insight` 与关系行。关系目标三级落点：同文件 → `[[#^块id]]`；跨文件且目标已有导出笔记（索引 derivedNotePath）→ `[[目标导出笔记#^块id]]`（Graph 才有边）；其余 → `obsidian://inklight?...` 协议链接，靠关系自带的锚点快照（targetOffset/targetPage/targetCfi/targetQuote）定位。老关系没有锚点快照时退回纯文本 `"路径#id"`，宁可不点也不生成假链接。章节**不要**写成 inline field（callout 标题里已有）；块外手写内容不受影响。关系只存有向引用，对方被删不会级联失效。
反查指针（index v3）: 索引条目带 derivedNotePath / blockIds / mocPaths / exportedAt / atomCards，导出后由 recordExportTargets 回写，**只写索引不写 sidecar**；saveDocument 必须经 pickExportFields 把这些字段带到新条目，否则改一条批注就丢一次指针。findOrphanBlocks 用「当前批注」而非索引里的 blockIds 比对（删批注时指针会保留旧值，拿它比永远看不到孤儿块）。createAtomCard 只新建卡片 md、不改 sidecar：卡片是**独立资产**，抽卡是一次性分叉，之后与批注互不同步（批注改了不回流，卡片内容也不会被重复提炼覆盖）。去重三级：索引 atomCards 快路径 → 扫描 atomCardFolder 里 frontmatter 的 `inklightId`（= `${mode}-${annotationId}`，命中则回写索引指针自愈）→ 新建。文件名只是人类可读标题（正文首句），可自由改；索引指针失效不影响认卡。
tags.ts: 标签归一化纯函数（去 #、折叠空白、剥离非法字符、大小写无关去重、并集）与 toObsidianTag/toObsidianTags（空格转连字符、剔 OB 非法字符、纯数字加前缀、保留 / 嵌套），无 IO。

法则: Markdown 只读·sidecar 持久·缓存加速·索引导航
